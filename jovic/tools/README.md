# Jovic content calendar: data, media and refresh

Victor's calendar lives at `jovic.puroflowmedia.com/calendar` (files in `jovic/calendar/`). It is a static page, built from the Adit calendar, with no build step. Three things feed it:

- `calendar/weeks.js`: the plan. Every post, caption, platform and time. Edited by hand.
- `calendar/stats.js`: the live links and numbers. Generated by `tools/refresh.mjs`. Never edit it by hand.
- `calendar/media/<week>/`: the reels (`<day>.mp4`, `<day>.jpg` poster, `p/<day>.mp4` card loop). Generated by `tools/build-media.mjs`.

**Rule: every Jovic post that is scheduled in Metricool (brand `8185392`) goes into `weeks.js` in the same session.** The calendar shows what Metricool will do, so the two have to match.

## Adding a post

1. In `calendar/weeks.js`, add a day to the right week (or a new week, with the next `media` folder, for example `media/w1207/`). Copy an existing day and change it:
   - `id`, `day`, `short`, `jump`, `date` (`11/20`), `title`, `bucket`, `video: true`
   - `times`: one entry per platform that posts that day, `{ "k": "ig", "t": "10:00 AM", "s": "Scheduled" }`. Platform keys: `ig`, `fb`, `tt`, `yt`, `li`. Times are Pacific. `s` is `Scheduled` or `Not scheduled`; the site changes it to Posted by itself once `stats.js` has that platform.
   - `hook`, `caption` (a list of paragraphs), `thought`, `cta`, `tags`, `drive` (link to the reel file)
2. Put the finished reel in a folder and run `node tools/build-media.mjs <folder>`. Add the day and the words in its file name to `tools/media-map.json` first.
3. Commit and push to main. Vercel deploys on its own.

## Reels

`node tools/build-media.mjs <folder with the originals> [w1116/thu="file name"] [--force]` writes 720p H.264 files of 14 MB or less, a poster frame, and the small silent card loops (it runs `tools/previews.sh`). The site plays these files directly, never an Instagram embed. Needs ffmpeg.

`tools/previews.sh` alone rebuilds only the card loops (`-f` for all). A missing loop falls back to the full file, so nothing breaks, it just loads heavier.

## Refresh the numbers

1. Pull the raw reports from Metricool, brand `8185392`, from `2026-11-19T00:00:00-08:00` to now. Save each result exactly as returned (`{"rows": [...]}`) in one folder, with the metrics in this order (any file can be missing; the last known numbers for that network are kept):

| File | Metric ids, in order |
|---|---|
| `ig_reels.json` | IGRE02, IGRE06, IGRE03, IGRE23, IGRE24, IGRE10, IGRE07, IGRE21, IGRE12, IGRE11 |
| `ig_posts.json` | IGPO02, IGPO06, IGPO03, IGPO07, IGPO28, IGPO14, IGPO13, IGPO08, IGPO27, IGPO15, IGPO29 |
| `fb_reels.json` | FBRE02, FBRE06, FBRE05, FBRE10, FBRE13, FBRE08, FBRE11 |
| `fb_posts.json` | FBPO02, FBPO06, FBPO07, FBPO03, FBPO11, FBPO12, FBPO13, FBPO08, FBPO14, FBPO16 |
| `li_posts.json` | LIPO02, LIPO08, LIPO04, LIPO12, LIPO16, LIPO13, LIPO10, LIPO18 |
| `tt_posts.json` | TKPO02, TKPO03, TKPO05, TKPO07, TKPO08, TKPO09, TKPO10, TKPO15 |
| `yt_videos.json` | YTVP02, YTVP05, YTVP17, YTVP06, YTVP08, YTVP09, YTVP11 |

2. `node tools/refresh.mjs --in <folder>`
3. Read the output. `tools/last-refresh.json` lists what it matched on its own and anything it could not place.
4. Commit `calendar/stats.js`, `tools/post-map.json` and `tools/last-refresh.json`, then push to main. It can run hourly; a platform flips from Scheduled to Posted, with its live link and numbers, on the first refresh after the post goes out.

## Matching posts to days

`post-map.json` says which native post belongs to which day (`<week id>/<day id>`). The refresh matches a day's own platforms to the rows posted on that Pacific date (closest to the planned time, with caption similarity as the tiebreak), then tries the days around it by caption. Posts that are not part of the calendar (Victor's own posts) go in `_ignore`.

A platform that is live but has no link or analytics row, like the LinkedIn personal profile, is flipped by hand: add `"_posted": ["li"]` to that day in `post-map.json`. It then shows Posted without numbers.

## Going live

`vercel.json` at the repo root needs the host route for `jovic.puroflowmedia.com` (the same pattern as `bookmark.puroflowmedia.com`): `^/$` goes to `/jovic/index.html` and everything else to `/jovic/$1`. Add the domain to the Vercel project, then push to main. `/jovic/calendar/` also works on any other host as a preview. `tools/` is in `.vercelignore`, so none of this ships.
